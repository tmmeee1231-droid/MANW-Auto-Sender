# 𝑀𝒜𝒩𝒲 Auto Sender

تطبيق Android يرسل الصور الجديدة التي تظهر في معرض الهاتف إلى محادثة تيليجرام يحددها المستخدم.

## الخصائص
- حفظ Bot Token و Chat ID داخل مساحة تخزين مشفّرة باستخدام Android Keystore.
- لا يبدأ إرسال الصور القديمة: يتم تسجيل وقت التفعيل كنقطة بداية.
- فحص دوري في الخلفية (WorkManager، كل 15 دقيقة كحد أدنى تقريبي).
- إيقاف المزامنة من داخل التطبيق.
- اختبار اتصال البوت.
- لا يحتوي المشروع على أي توكن مضمّن.

## البناء
افتح المشروع في Android Studio (Giraffe أو أحدث) واترك Gradle يحمّل الاعتماديات، ثم اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

## الإعداد
1. أنشئ Bot Token جديدًا من @BotFather إذا سبق نشر توكن قديم أو مشاركته.
2. افتح التطبيق وأدخل التوكن الجديد و Chat ID.
3. اضغط تشغيل المزامنة ووافق على إذن الصور.
4. سيُرسل التطبيق الصور الجديدة بعد وقت التفعيل فقط.

## الخصوصية
المزامنة لا تعمل إلا بعد تفعيلها يدويًا ومنح إذن الصور. لا توجد ميزة إخفاء أو إرسال خفي. أوقفها من زر إيقاف المزامنة.
